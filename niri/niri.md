## Niri

You can install niri by following their guide from their [website](https://niri-wm.github.io/niri/Getting-Started.html) or [wiki](https://github.com/niri-wm/niri/wiki/Getting-Started).  

By default niri will be installing:
- Alacritty as its terminal
- Fuzzel as the launcher
- Swaylock as the lock sreen manager
- Mako as the notification daemon
- xdg-desktop-portal-gtk, xdg-desktop-portal-gnome, gnome-keyring, plasma-polkit-agent, xwayland-sattelite

You can configure niri by going in `~/.config/niri/config.kdl`.

Copy the configuration from the git clone with:

```sh
cp ~/path/to/the/cloned/repository/linux-configs/niri/config.kdl ~/.config/niri/
```
