## Font

The font that is used in this configuration is **JetBrains Mono Nerd Font**

You can install JetBrains Mono Nerd Font from the [nerd fonts website](https://www.nerdfonts.com/font-downloads). 

After downloading the font files, you need to extract it and put it either globally or user only. You can do this by:

### Font:

```sh
unzip JetBrainsMono.zip jetbrains-mono-nerd-font    # Extract and rename the folder
sudo mv jetbrains-mono-nerd-font /usr/share/fonts   # Move the folder to system (globally) 
mv jetbrains-mono-nerd-font ~/.local/share/fonts    # Move the folder to user (user-only)
```
