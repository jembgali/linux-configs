## Cursor

The cursor that is used in this configuration is **BreezeX-Dark Cursor** 

You can install BreezeX-Dark from its [repository](https://github.com/ful1e5/BreezeX_Cursor)

After downloading cursor files, you need to extract it and put it either globally or user only. You can do this by:

### Cursor:

```sh
tar -xvf BreezeX-Dark.tar.gz         # Extract the folder
mv BreezeX-* ~/.local/share/icons    # Move the folder to system (globally)
sudo mv BreezeX-* /usr/share/icons   # Move the folder to user (user-only)
```
