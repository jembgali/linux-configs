# Noctalia

You can install noctalia from their [website](https://docs.noctalia.dev/noctalia/getting-started/installation/). The guide for the installation is all there.

To apply the custom settings that is here, you will need to copy or move it to `~/.local/state/noctalia`. You would also need to wallpapers that are currently used, so you can ask the owner for their **Wallpapers folder** for that.

To copy the custom settings to noctalia, you will need to do:

```sh
cp ~/Downloads/linux-configs/noctalia/settings.toml ~/.local/state/noctalia
```
